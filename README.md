# Рулетка выбора

Простое статическое приложение в формате колеса фортуны.

## Что умеет

- пользователь добавляет названия секторов через поле ввода;
- после подтверждения появляется следующая строка;
- максимум 10 секторов;
- цвета секторов идут по очереди: розовый, красный, синий;
- если количество секторов нечётное, последний сектор становится перламутровым;
- колесо запускается кнопкой в центре;
- вращение длится случайно от 3 до 12 секунд;
- скорость каждый раз разная, старт быстрый, остановка плавная;
- сверху у колеса есть стрелочка-указатель.

## Запуск

Откройте `index.html` в браузере.
